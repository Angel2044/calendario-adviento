# 🎄 Calendario de Adviento

Calendario de adviento web con 25 tarjetas que se desbloquean cada día de diciembre (el día 1 la primera, el día 2 la segunda y la anterior, etc.). Pensado para verse en el móvil.

## Editar el contenido
Los textos, títulos y emojis de cada día están en [`days.js`](days.js).

## Probar sin esperar a diciembre
- `?preview` → muestra todos los días desbloqueados.
- `?dia=10` → simula que hoy es 10 de diciembre.

## Publicación
Se publica gratis con GitHub Pages desde la rama `main` (carpeta raíz).
